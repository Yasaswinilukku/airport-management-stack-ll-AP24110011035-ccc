# Abstract

This project implements an **Airport Management System** using **Stack (Linked List)** in C.  

Flights waiting to **land** or **depart** are managed using two stacks.  
The system supports push, pop, and display operations for both stacks.  
It demonstrates how **LIFO principle** is applied in real-life runway scheduling.  

The project is menu-driven, simple, and illustrates practical use of **stack data structure**.
